# Instructions



In this assignment, you will apply cryptanalysis techniques to decrypt a file that has been encrypted using a Caesar cipher. Your goal is to retrieve the original content of the file, determine its type, and provide the code used for your decryption process.

**Assignment Details:**

* You have been provided with a file named tanase_vlad (e.g., john_doe).
* This file has been encrypted using a Caesar cipher with an unknown shift key.
* Your task is to decrypt the file, retrieve the original content, and identify the file type ([https://en.wikipedia.org/wiki/List_of_file_signatures](https://en.wikipedia.org/wiki/List_of_file_signatures))

**Steps:**

* Decrypt the file by determining the correct shift value used in the encryption.
* Retrieve the original content and analyze it to identify its type. The formats used for encryption were: 3GP, AVI, BMP, JPG, EXE, XLS, XLSX, PPT, PPTX, DOC, DOCX, PDF, MP3, Mp4, PNG, TAR.GZ

**Hints**

The file, grep commands (Linux/macOS) or tools like binwalk can help identify file types.
